# E-Commerce Profit Analysis

## Overview
This project analyzes retail sales data from the Superstore dataset to identify sales trends, profitability patterns, and customer segment performance.

## Objectives
- Analyze monthly sales trends
- Compare category-wise sales and profits
- Identify top-performing customer segments
- Evaluate sales-to-profit ratios
- Generate business insights from retail data

## Tools Used
- Python
- Pandas
- Plotly
- Jupyter Notebook

## Dataset
Sample Superstore Dataset

## Key Insights
- Technology generated the highest profits.
- Consumer segment contributed the highest sales.
- Sales-to-profit ratios varied significantly across segments.
